# REEL 001 — The Director Is a File

**Format:** Premium proof film, 26 seconds, vertical 1080×1920, 30 fps (780 frames). Working brand: CLAUDE DIRECTED (subject to name clearance).

**One-line premise:** A piece of stunning motion design is not produced by one magic sentence; a deliberately engineered directing workflow orchestrates story, shots, motion, sound and quality review.

**Audience:** Claude Code users, motion designers, short-form content creators, agency operators. **Emotion:** Wonder -> curiosity -> confidence.

**Hook:** First visible frame already contains a beautiful moving typographic/physical event, not a question card. Example: a bright line tears through a realistic dark surface and turns into a sharply lit composited cinematic frame. The exact effect must be rendered or sourced before claiming completion.

**Tension:** "What made that?" Show brief intuitive misconception "ONE PROMPT?" (as a question, not a false before/after).

**Revelation:** Peel finished video into actual modules: STORY / SHOTS / MOTION / SOUND / QA, then watch them integrate. Demonstrate real file names or interface excerpts from the working project, not decorative fabricated code.

**Payoff:** Replay the opening shot with added meaning: viewers now understand its engineered system.

**CTA:** "Comment DIRECTOR — get the free starter workflow." This must link to a real free starter pack, not to the paid product or waitlist by surprise.

**Tech stack:** Remotion for 2D/editorial motion. Source/pre-rendered Blender or licensed footage for dimensional effects when needed. FFmpeg for final checks. Use known original or licensed audio. Record honest credits and dependencies.

**Signature effects:** physical-to-graphic match cut, precision kinetic type, spatial layer split/reassembly, restrained parallax, bass/silence contrast. Source technique family: EYECANDY; do not rehost EYECANDY examples.

**End-loop:** Last composition returns to the same moving graphic shape/lighting direction as the first frame, so a replay feels natural. CTA must remain visible/readable before the final transition.

**Editorial constraints:** no black/title intro, no generic AI neural-network animation, no fake code screen, no 3D transition lacking actual source assets, no more than five words of large title type per beat.

# Pre-publish release gates

1. Promise match: opening outcome shown, content substantiates claim, promised free asset exists.
2. Visual clarity: action readable at native phone viewing scale; safe-zone check against Instagram UI elements; typography never clips.
3. Story: hook -> tension -> escalation -> payoff -> natural ending. No unnecessary scene.
4. Craft: no jumpy easing discontinuities, duplicate frames, flicker, exposure mismatch, sloppy key edges or overly smeared motion blur.
5. Sound: Foley cause/effect timing; musical arc; voice intelligible; check mono compatibility; short-term harshness; measure integrated LUFS and true peak. Suggested mastering starting point -16 to -14 LUFS with <=-1 dBTP; adjust by content/platform; not a platform guarantee.
6. Editing: identify each match cut's visual correspondence; use sound bridges intentionally; hold reactions when needed.
7. Provenance: asset log, permissions, credit where required, no copy of EYECANDY footage or uploaded benchmark video.
8. Truth: disclose if a "process" depiction is conceptual; confirm that any code/project being demonstrated really functions.
9. Tech: export metadata, no audio start/end glitches, no unintended black first frame, final loop continuity.
10. Funnel: comment trigger set to correct Reel, keyword matching tested from another account, delivery links active, free asset actually downloadable, respectful follow-up only after appropriate user interaction.

Attach an issue log by timecode, expected behavior, problem and correction. Reject the Reel if any critical item fails.
